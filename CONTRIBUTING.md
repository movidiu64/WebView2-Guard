# Contributing to WebView2 Guard

Thanks for your interest. Bug reports, ideas and pull requests are welcome.

## Reporting a bug or asking for a feature

Open an [issue](https://github.com/movidiu64/WebView2-Guard/issues). For a bug, please include the WebView2 Guard version, your operating system, the steps that lead to the problem, what you expected and what happened, and any error message.

## Pull requests

For anything larger than a small fix, open an issue first so we can agree on the approach before you spend time on it.

- Code, comments, commit messages and documentation are in English.
- Add tests for new behavior; the existing tests must pass (`dotnet test tests/WebView2Guard.Tests`).
- Describe user-visible changes under `## [Unreleased]` in `CHANGELOG.md`.
